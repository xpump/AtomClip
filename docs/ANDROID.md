# Android 功能与限制

最低 Android 8.0 / API 26，目标 API 35。APK 为原生 Android 应用，无需 Google 服务。安装同一套构建的 `AtomClipBLE.apk`，首次连接授予系统所需权限。

## 与 Windows 外网端的对照

| 功能 | Windows 外网 EXE | Android 0.1.0 |
| --- | --- | --- |
| 编辑文字、读取剪贴板、手动发送 | 支持 | 已实现 |
| 中文、多行、emoji、16 KiB 限制 | 支持 | 协议测试通过 |
| 有内网程序时双向传输 | 支持 | 已实现；手机前台接收后写入系统剪贴板 |
| 无内网 EXE / 无文件的常驻接收设置 | 四步向导 | 已补齐同样的四步流程；无需先用 Windows 设置 |
| 无内网 EXE 双向传输 | 选择 PowerShell，默认双向，内网按 B 切换 | 相同；手机保持前台接收 |
| 无 PowerShell 的直接键盘输入 | GBK / VUC 中英文混排，另保留 ASCII | 相同；输入方式按钮直接可见、试输可选；单向 |
| GBK 高速、兼容速度 | 严格无损编码，未知字符提示 VUC | 相同；固件能力第九字节门控，需支持 GBK 的配套固件 |
| 启动后数据输入加速 | 快速 1 ms / 兼容 4 ms | 相同；第七状态字节检测并回退旧固件 |
| 系统启动等待与进度 | 3–60 秒，默认 10 | 第一步可设置；显示估算范围及已用时间 |
| 固定 PowerShell 打开指令 | 支持 | 已实现，相同的三字节认证指令 |
| 临时 USB 键盘写入 | 支持，可选自动粘贴 | 支持，确认窗口中可选自动粘贴 |
| AES-GCM、认证回执、重试、去重 | 支持 | 桌面 JVM 与实际 C# 协议互测通过 |
| 暂停、恢复、断线重连 | 支持 | 已实现；前台重连，返回前台后重连 |
| 自动发送新复制文字 | 托盘后台可用 | 仅应用有焦点并在前台时可选开启；不补发旧内容 |
| 离开应用、锁屏时后台同步 | 支持 Windows 托盘运行 | 不提供；受 Android 剪贴板及生命周期限制 |
| 日志保存和导出 | 7 天轮换、打开目录 | 7 天轮换、通过系统文件选择器导出 |
| 新开发板 USB 烧录 | 已内置固件及工具 | 不提供，使用 Windows 外网 EXE |

以上“已实现”表示源码和 APK 中具备对应功能，不代表已经在手机上运行验收。目前没有可用 Android 手机，未宣称实际 BLE、系统剪贴板、权限流程或厂商系统兼容性测试通过。

## 操作

1. 关闭或断开 Windows 外网 BLE 客户端，保持开发板插在内网。
2. 安装并打开 APK，点击 **连接开发板**。
3. Android 8–11：授予定位权限并开启定位；Android 12 及以上：授予附近设备权限。保持系统蓝牙开启。
4. 选择“有内网程序”，或在“无内网程序”中选择 **PowerShell / 仅 USB 键盘**。PowerShell 按四步向导设置，默认双向，内网窗口按 B 切换回传。键盘模式以可见按钮选择 GBK / VUC / 纯英文，默认直接输入正文；可选“发送前先试输”，开启后才需核对并确认试输结果。
5. 输入文字，或点击 **从剪贴板填入**，再点击发送。收到认证回执后，在内网 Ctrl+V。

内网已经有接收器时，无需重复初始化。只有一个 BLE 客户端能连接；从 Windows 切换到手机，需先断开 Windows。

进入其他应用、系统文件选择器或锁屏会关闭 BLE 连接。返回后仅恢复连接，不自动补发旧文字；未确认的手动发送保留在编辑框内，需要重新核对、发送。Android 的前台自动剪贴板选项不等同于在其他应用中复制即后台发送。
