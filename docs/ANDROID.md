# Android 0.2.0

VUC 默认按键间隔 4ms、确认等待 80ms；选择 VUC 后可点“自定义速度”保存参数或恢复兼容速度。设置保存于本机，旋转及重启后沿用。

Android 8.0+、versionCode 61。沿用原签名可覆盖安装，私人 / 公开配套不得混用。新版保留紧凑 Apple 风格三页签、GBK / VUC / 纯英文分段选择、可选试输和同 Activity 全屏编辑。软键盘展开时保留编辑工具及发送区域；旋转保留各模式草稿和撤销历史，发送完成不清空正文。

“我的开发板”可 USB 绑定、选择目标、加密导入导出配置，完整编号经认证后才进入可发送状态。附近扫描读取完整编号后合并到同一列表；短号相同或未读到编号不会误合并。默认只重连选定的已确认记录，已移除旧固件兼容连接。

添加操作：点击“添加开发板 → 读取开发板 → 确认添加”。只有一个可用原生 CDC 设备时直接请求系统 USB 权限，多个设备时明确选择。已绑定板改为“使用已有绑定”，待确认记录改为核对原配置。恢复、导出和清除操作收在“更多”。

## 手机 USB OTG 烧录

1. 先按[支持矩阵](BOARDS.md)核对板型。手机需支持 USB Host / OTG，通过数据线 / 转接头连接板的原生 USB，手动进入 ROM 下载模式。仅 USB-UART 口不能用于本原生 CDC 实现。
2. 更多 → 开发板设置 → 选择板型 → 识别 USB 设备，允许系统 USB 权限。读取芯片、安全状态、容量、Flash 类型和分区表。
3. 分区兼容时保留绑定升级；首次安装 / 不兼容分区时先加密备份已有绑定，明确选择清空安装。确认板型及覆盖范围后开始。
4. 保持供电和前台。旋转保留烧录会话，离开前台中止。拔线、拒绝权限、超时、错误芯片 / 容量 / 校验失败均不能显示成功；重新进入下载模式并识别重试。
5. 只有所有固件段校验成功才显示完成。拔插后在正常 USB 模式通过“我的开发板”绑定或恢复配置，再移板到内网连接蓝牙。

烧录期间暂停蓝牙与发送。APK 只提供内置四种 S3 板型的固件，不支持任意 BIN 导入、OPI Flash、加密 Flash 或其他芯片。常规升级不会写 NVS 绑定区；清空安装会删除全部板上数据。

## 使用限制

PowerShell 默认双向、内网按 B 切换。只允许 USB 键盘时，GBK / VUC 仅单向输入到光标，不能读取内网剪贴板。应用须在前台接收、写入手机剪贴板；没有跨应用后台剪贴板同步。一次只连接一个外网客户端。

说明文字采用 sp，常用操作目标为 360×800dp 默认字号收起键盘时一屏；小屏、横屏和大字体允许滚动。编辑工具为粘贴、撤销、清空、全屏 / 收起；清空立即执行，可撤销。全屏复用文本框，保留光标，避免 Activity 切换断连。

本次针对手机截图反馈修复 VUC / GBK 双行选中框：关闭横向基线对齐，按最高文字内容测量后统一选项高度，48dp 仅为最小值。普通 / 全屏共用的四个编辑按钮增加 8dp 间距、使用浅色文字按钮，保留至少 48dp 点击高度。修复后 APK 已构建，尚未在手机上确认裁切问题消失。
