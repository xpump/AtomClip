# 0.2.1 验证记录（本地审查包）

2026-10-19。Windows 0.2.1.0；Android 0.2.1 / 59；固件 0.2.0。本轮已完成源码修改、构建和桌面回归，硬件未验收，不是正式发布版。历史 0.2.0 验证见 [VALIDATION_020.md](VALIDATION_020.md)。

## 本轮修改

- 按完整 Info 编号合并已绑定设备与附近广播，短号相同不合并，读取失败保持“编号未读取”，多地址同完整编号明确显示冲突。列表合并不修改绑定、密钥或当前目标；实际连接继续完整编号核对和双向认证。
- Windows 主操作为连接、添加开发板、扫描附近、更多。USB 添加读取后识别已确认或待确认记录，优先核对原绑定，默认保留已有正文配对。Android 采用同样规则，单 USB 候选直接读取，多候选明确选择。
- 删除旧固件服务 UUID、地址选择 UI、明文发送 / 接收分支。旧 ACBS2 配置仍可读取，旧目标禁用，V2 绑定及待确认记录保留。
- 前轮 Android 双行选项高度、8dp 编辑按钮间隔，以及两端编辑、全屏、草稿、撤销和防闪烁保持。

## 待实机验证

本轮只枚举 Windows 串口名称以呈现界面，没有读取、写入或扫描真实开发板。USB 自动识别已有绑定、BLE 完整编号合并 / 多板冲突 / 超时 / 重连、真实烧录和掉电恢复仍需实物确认。

Android 界面、VUC / GBK 选中框、工具间隔、小屏 / 横屏 / 大字体 / 软键盘 / 旋转、Keystore、USB 权限、OTG，以及 HID / 目标输入法均待手机与开发板实测。编译和模拟不能代替这些验收。Windows 多 DPI 和辅助技术未穷尽。

USB 键盘仅单向输入，不能读取内网剪贴板。已正常使用 0.2.0 V2 固件及绑定的板无需为 0.2.1 客户端更新重烧。
