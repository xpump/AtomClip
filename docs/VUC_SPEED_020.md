# 0.2.0 公开配套整合与 VUC 速度更新

2026-10-19。按用户要求统一显示版本为 **0.2.0**，仅制作公开配套。保留此前工作版的设备列表合并、USB 添加简化、Windows 蓝牙连接修复和 Android 编辑布局修复。历史 0.2.1 / 0.2.2 记录保留用于追溯，不代表当前交付版本。

## VUC 输入

旧默认参数为按键间隔 1ms、确认及中英切换等待 35ms。用户反馈在其目标输入法上会乱码，使用兼容速度后可正常输入。本版首次使用 VUC 默认采用 **4ms / 80ms**，无需勾选。

选择 VUC 后点击 **自定义速度…**，可分别设置按键间隔 1–50ms、确认 / 中英切换等待 20–200ms。数值越小越快；保存后用于正文与试输，改变速度会清除先前的试输确认。**恢复兼容速度 → 保存** 回到 4ms / 80ms，取消不修改现有设置。两端保存至本机，重新启动后沿用。GBK 的兼容速度、纯英文及 PowerShell 的速度设置各自独立。

预计耗时与超时按所选参数计算，包含 VUC 字符确认和中英切换等待。自定义值在客户端校验范围，并通过既有 TypeJob 格式发送；协议及固件不变，已正常绑定的开发板无需重刷。
