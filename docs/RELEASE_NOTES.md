# AtomClip 0.1.0

首次整理发布：通过 AtomS3U 的 USB + BLE，在 Windows 内网电脑与外网 Windows / Android 设备之间传递纯文本。

## 主要功能

- 有内网程序：双向剪贴板同步，支持中文、英文、多行与 emoji。
- PowerShell：四步设置后默认双向，内网窗口按 B 切换回传。
- 仅 USB 键盘：GBK / VUC 中英文混排和纯英文，方式直接可见，试输可选。
- Windows 外网端内置开发板烧录向导，内网端保持不超过 64 KiB 的单文件。
- 认证回执、重试、去重、暂停和状态日志；单条最多 16 KiB。

## 获取与构建

公开发布源码。按 README 和 `docs/DEVELOPMENT.md` 生成独立配对的一套程序，Windows、Android、固件必须使用相同配对材料。

## 已知限制

- 仅 USB 键盘为单向输入，不能读取内网剪贴板；GBK / VUC 依赖目标系统、输入法和程序兼容性，不支持任意 Unicode。
- Android 需保持前台，没有跨应用后台同步或手机 USB 烧录。
- 仅传输纯文本，不传输图片、文件和富文本。
- 实际 HID 漏字率、目标窗口兼容性和 Android 真机流程仍待验收。

本版本是内部开发版的整理编号。原使用开发版 0.5.4 / 0.5.5 固件且配对未改变的用户无需重烧；新配对构建需更新整套程序和开发板。
