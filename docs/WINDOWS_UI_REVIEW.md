# Windows 0.2.1 界面检查

2026-10-19。使用最终构建的真实 WinForms 控件，离屏渲染默认及最小窗口。测试采用独立目录、合成密钥和标注为模拟的开发板记录；没有调用 BLE 扫描、串口读取或用户配置。与桌面截图不同，这是控件渲染证据，不代表实机蓝牙验证。

## 统一开发板列表
